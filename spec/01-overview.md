# 01 · 项目概述

## 1.1 项目名称

**MedSearch - PubMed 医学文献 AI 查询系统**

## 1.2 项目定位

为医生和医学生提供 H5 AI 助手应用，用于查询疾病相关的 PubMed 文献资料并生成 AI 总结。

## 1.3 背景与痛点

在医学研究领域，科研人员每天需要查阅大量文献来跟踪最新研究进展。然而，面对 PubMed 等全球权威数据库中海量的医学文献，传统的人工检索方式效率低下：

| 痛点 | 具体表现 |
|------|----------|
| 检索效率低 | 关键词搜索结果动辄成千上万篇，筛选耗时费力 |
| 理解门槛高 | 专业术语晦涩难懂，理解门槛高 |
| 语言障碍 | 跨语言文献阅读困难重重 |
| 时间成本高 | 医学研究者平均每天花费 3-4 小时在文献检索和阅读上，严重挤占科研创新时间 |

## 1.4 目标用户

- **医生**：临床诊疗中需要快速检索疾病相关的最新文献，辅助决策。
- **医学生**：学习与科研起步阶段，需要高效查阅文献、理解研究进展。
- **医学研究人员**：追踪前沿研究、撰写综述、开展课题。

## 1.5 核心价值

本项目旨在通过 AI 技术重塑文献查询体验，让科研人员从「大海捞针」的困境中解放出来，专注于更有价值的科研工作：

1. **智能关键词生成**：输入自然语言疾病描述，AI 自动提取核心关键词并构建 PubMed 检索策略。
2. **精准文献检索**：关键词自动翻译为英文，调用 PubMed API 返回真实文献与总数。
3. **中文友好**：文献标题自动翻译为中文，摘要 AI 精炼，降低语言与理解门槛。
4. **AI 总结报告**：为勾选文献生成结构化总结（关键发现、研究趋势、临床意义）。

## 1.6 项目目标与成功指标

| 维度 | 指标 | 目标值 |
|------|------|--------|
| 功能 | 关键词生成准确率 | AI 生成的关键词与用户检索意图一致 |
| 功能 | 文献真实性 | 返回的文献均来自 PubMed，PMID 可溯源 |
| 性能 | 检索响应时间 | 单次检索（含翻译+API 调用）≤ 5 秒 |
| 性能 | 总结生成时间 | 单篇文献总结 ≤ 10 秒 |
| 体验 | 总结质量 | 结构化、专业、可读，分三个维度呈现 |
| 体验 | 移动端适配 | H5 在主流手机尺寸正常显示与交互 |

## 1.7 项目范围

### 范围内（MVP）

- 四大板块页面：Header / Search / Literature / Summary。
- 关键词生成、添加/删除、翻译、检索。
- 文献列表分页展示（每页 9 篇）、勾选多篇。
- AI 总结生成与文献详情卡片展示。
- 查看原文跳转 PubMed。

### 范围外（后续迭代）

- 用户账号体系与检索历史。
- 文献收藏、导出（BibTeX/EndNote/PDF）。
- 更多数据库（PMC、Cochrane、Embase 等）。
- 原生 App、离线缓存、推送订阅。

## 1.8 关键术语

| 术语 | 说明 |
|------|------|
| PMID | PubMed 文献唯一标识符 |
| E-utilities | PubMed 官方提供的 RESTful 检索接口（esearch/efetch） |
| MaaS | Model as a Service，华为云大模型服务，提供文本生成/翻译能力 |
| H5 | 移动端网页应用（移动端浏览器访问） |
