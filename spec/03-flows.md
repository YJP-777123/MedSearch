# 03 · 核心功能流程

## 3.1 关键词生成流程

```
用户输入疾病描述（10-300字）
        │
        ▼
点击「生成关键词」
        │
        ▼
前端校验：非空、长度 10-300 字  ──失败──► 提示错误
        │通过
        ▼
后端调用 MaaS（Prompt：提取 3 个中文医学关键词）
        │
        ▼
返回 3 个中文关键词
        │
        ▼
前端渲染为蓝色渐变标签（可删除）
```

**关键点**
- 描述输入：10-300 字符。
- AI 输出：固定 3 个中文关键词。
- 用户可删除任意关键词，也可手动添加。
- 关键词上限 5 个（3 个 AI 生成 + 最多再手动添加 2 个，或删除后替换）。

## 3.2 文献检索流程

```
用户点击「开始检索文献」
        │
        ▼
前端校验：至少 1 个关键词  ──失败──► 提示「请先生成或添加关键词」
        │通过
        ▼
后端：将中文关键词翻译为英文
        │
        ▼
后端：调用 PubMed E-utilities（esearch）
        │  构建检索式（多关键词 AND 组合）
        ▼
获取 PMID 列表 + 文献总数 totalCount
        │
        ▼
后端：调用 efetch 获取文献详情（标题/作者/摘要/日期）
        │
        ▼
后端：调用 MaaS 翻译标题为中文 + 摘要精炼（≤100字）
        │
        ▼
返回文献列表（每页 9 篇）
        │
        ▼
前端渲染文献列表，显示 totalCount 与筛选 9 篇提示
```

**关键点**
- 检索式构建：多个英文关键词之间用 `AND` 连接。
- 每页返回 9 篇，前端按页请求（或一次性返回后前端分页，需在开发前确认）。
- 标题中文翻译、摘要 AI 精炼（不超过 100 字）。

## 3.3 总结生成流程

```
用户勾选多篇文献
        │
        ▼
点击「生成AI总结」
        │
        ▼
前端校验：至少勾选 1 篇  ──失败──► 提示「请先勾选文献」
        │通过
        ▼
后端：对每篇文献调用 MaaS 生成结构化总结
        │  （关键发现 / 研究趋势 / 临床意义）
        ▼
返回每篇文献的总结
        │
        ▼
前端渲染 SummarySection 文献详情卡片
        │
        ▼
点击「查看原文」→ 跳转 PubMed
```

**关键点**
- 每篇勾选文献单独生成一份总结。
- 总结结构固定为三个维度：关键发现、研究趋势、临床意义。
- 卡片展示：中文标题 / 英文标题 / 作者（前 3 位，超出显示"..."）/ 发布日期 / PMID / 查看原文。

## 3.4 页面状态机

| 状态 | 触发 | 表现 |
|------|------|------|
| 初始态 | 页面加载 | 仅 Header + Search，文献/总结区为空 |
| 生成关键词中 | 点击「生成关键词」 | 按钮 loading，禁用 |
| 关键词就绪 | 关键词返回 | 显示标签，可增删 |
| 检索中 | 点击「开始检索文献」 | 检索按钮 loading，文献区骨架屏 |
| 检索完成 | 文献返回 | 显示文献列表与总数，可勾选/分页 |
| 总结生成中 | 点击「生成AI总结」 | 总结按钮 loading，总结区骨架屏 |
| 总结完成 | 总结返回 | 显示文献详情卡片 |
| 错误态 | 任一接口失败 | 展示错误提示 + 重试按钮 |

## 3.5 异常处理

| 异常 | 处理策略 |
|------|----------|
| 描述过短/过长 | 前端拦截，给出明确提示 |
| 无关键词检索 | 前端拦截提示 |
| 未勾选即总结 | 前端拦截提示 |
| MaaS 调用超时/失败 | 后端返回错误码，前端提示并支持重试 |
| PubMed 检索无结果 | 返回 totalCount=0，前端提示「未检索到相关文献，请调整关键词」 |
| PubMed API 限流 | 后端控制请求频率（≤3 req/s），失败重试一次 |
| 翻译/总结内容异常 | 后端校验输出非空，异常时降级返回原文 |
