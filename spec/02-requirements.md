# 02 · 功能需求与页面布局

## 2.1 功能需求总览

| 编号 | 功能 | 说明 | 优先级 |
|------|------|------|--------|
| F1 | 关键词生成 | 输入疾病描述（10-300 字），AI 生成 3 个中文关键词 | P0 |
| F2 | 关键词管理 | 添加/删除关键词，最多 5 个 | P0 |
| F3 | 文献检索 | 中文关键词翻译为英文，调用 PubMed API | P0 |
| F4 | 文献列表 | 每页 9 篇、分页展示、勾选多篇 | P0 |
| F5 | AI 总结 | 为勾选文献生成结构化总结 | P0 |
| F6 | 文献详情 | 展示标题/作者/PMID，跳转 PubMed 原文 | P0 |

## 2.2 页面布局（从上到下四个板块）

页面整体为单页 H5 应用，从上到下依次为：

```
┌────────────────────────────────────────────┐
│  板块一：HeaderSection（顶栏）               │
├────────────────────────────────────────────┤
│  板块二：SearchSection（检索关键词）         │
├────────────────────────────────────────────┤
│  板块三：LiteratureSection（文献列表）       │
├────────────────────────────────────────────┤
│  板块四：SummarySection（文献详情/总结）     │
└────────────────────────────────────────────┘
```

---

## 2.3 板块一：HeaderSection

**标题**：网站名称 `MedSearch - PubMed医学文献AI查询系统`

### 构成

| 元素 | 说明 |
|------|------|
| Logo | 左侧品牌 Logo（图标） |
| 主标题 | `MedSearch` |
| 副标题 | `PubMed医学文献AI查询系统` |

### 交互
- 静态展示，无交互。
- 可选：点击 Logo/标题回到页面顶部。

---

## 2.4 板块二：SearchSection（MedSearch 检索关键词）

### 标题与副标题

| 元素 | 内容 |
|------|------|
| 标题 | `MedSearch检索关键词` |
| 副标题 | `输入疾病/病理/研究方向，MedSearch将自动提取核心关键词并构建PubMed检索策略。例：肺腺癌的EGFR突变与预后相关性` |

### 布局（三行）

**第一行：检索输入框 + 「生成关键词」按钮**

| 元素 | 说明 |
|------|------|
| 检索输入框 | 2 行高度，最多 300 字，placeholder 如「请输入疾病描述或研究方向...」 |
| 生成关键词按钮 | 触发 AI 关键词生成 |

**第二行：关键词标签展示**

| 元素 | 说明 |
|------|------|
| 关键词标签 | 蓝色渐变背景，每个标签带 `×` 可删除，最多 5 个 |

**第三行：「新的关键词」输入框 + 「添加」按钮 + 「开始检索文献」按钮**

| 元素 | 说明 |
|------|------|
| 新的关键词输入框 | 单行输入，用于手动添加关键词 |
| 添加按钮 | 将输入的关键词加入标签列表 |
| 开始检索文献按钮 | 触发文献检索流程 |

### 校验规则

| 规则 | 处理 |
|------|------|
| 描述输入为空或 < 10 字 | 禁用「生成关键词」，或点击时提示「请输入至少 10 字描述」 |
| 描述输入 > 300 字 | 输入框截断/计数提示，禁止超出 |
| 关键词标签已满（5 个） | 「添加」按钮禁用，提示「最多 5 个关键词」 |
| 添加空关键词 | 忽略或提示 |
| 添加重复关键词 | 去重，提示「关键词已存在」 |
| 点击「开始检索文献」时无关键词 | 提示「请先生成或添加关键词」 |

### 功能说明
- AI 生成 3 个中文关键词。
- 搜索时，中文关键词翻译为英文后构建 PubMed 检索策略。

---

## 2.5 板块三：LiteratureSection（文献列表）

### 标题与副标题

| 元素 | 内容 |
|------|------|
| 标题 | `文献列表` |
| 副标题 | `检索到{totalCount}条PubMed医学文献，已为您筛选 9 篇相关文献，请勾选文献，MedSearch将为您生成专业的总结报告。`（`{totalCount}` 为动态值） |

### 文献列表（每行）

| 列 | 说明 |
|----|------|
| 序号 | 1、2、3 ... |
| 复选框 | 勾选用于生成总结 |
| 文献标题 | 中文标题 |
| PMID | 文献唯一标识 |

### 选择信息行

| 元素 | 说明 |
|------|------|
| 左侧 | `已选择 X 篇文献`（动态） |
| 右侧 | `当前第X页，共Y页`（动态） |

### 操作按钮

| 按钮 | 说明 |
|------|------|
| 更多文献 | 加载下一页（分页） |
| 生成AI总结 | 为已勾选文献生成总结 |

### 功能与规则

| 规则 | 处理 |
|------|------|
| 每页 9 篇 | 固定分页大小 |
| 分页 | 支持上一页/下一页/页码跳转（或「更多文献」累加式加载，需在开发前确认其一） |
| 勾选多篇 | 可跨页勾选，状态保持 |
| 未勾选点击「生成AI总结」 | 提示「请先勾选文献」 |
| 文献标题翻译 | 英文标题 AI 翻译为中文 |

> **待确认项（开发前需拍板）**：分页交互采用「传统页码分页」还是「更多文献」按钮累加加载。本规格默认按需求文案实现「更多文献」累加加载，同时保留页码提示。

---

## 2.6 板块四：SummarySection（文献详情）

### 标题与副标题

| 元素 | 内容 |
|------|------|
| 标题 | `文献详情` |
| 副标题 | `MedSearch已为您检索的文献生成专业总结` |

### 每篇文献卡片

**第一行**：文献标题（中文）
**第二行**：文献标题（英文）
**第三行**：`作者（前3位，超过显示"..."）| 发布日期 | PMID | 「查看原文」按钮`

**下方三个维度**：

| 维度 | 说明 |
|------|------|
| 关键发现 | 要点列表 |
| 研究趋势 | 要点列表 |
| 临床意义 | 要点列表 |

### 功能说明
- 每篇勾选文献单独生成一张总结卡片。
- 点击「查看原文」跳转 PubMed（`https://pubmed.ncbi.nlm.nih.gov/{PMID}/`）。

---

## 2.7 非功能需求

| 类别 | 要求 |
|------|------|
| 响应式 | H5 适配移动端（375px-768px 宽度优先），桌面端居中限宽展示 |
| 性能 | 关键接口见 1.6 节性能指标 |
| 容错 | API 失败/超时给出友好提示，可重试 |
| 加载状态 | 检索、翻译、总结过程展示 loading 状态 |
| 无障碍 | 按钮/输入框具备可读标签与焦点态 |
