# 06 · 设计规范

> 前端界面使用 `frontend-design` SKILL 设计，增加页面整体美感，避免页面的 AI 化设计。

## 6.1 设计目标

- **专业可信**：医学/科研场景，传达严谨、可信赖的气质。
- **简洁高效**：信息层级清晰，操作路径短，降低阅读与操作负担。
- **去 AI 化**：避免模板化的 AI 设计痕迹，呈现真实产品质感。

## 6.2 色彩体系

| 用途 | 色值建议 | 说明 |
|------|----------|------|
| 主色（品牌蓝） | `#2563EB` 系 | 医疗科技信任感 |
| 关键词标签 | 蓝色渐变（如 `#3B82F6 → #2563EB`） | 需求指定蓝色渐变背景 |
| 辅助色 | 中性灰 `#64748B`、浅底 `#F8FAFC` | 层次分隔 |
| 强调/成功 | 绿色系（如 `#16A34A`） | 选中/成功态 |
| 警示/错误 | 红色系（如 `#DC2626`） | 校验错误提示 |

> 注意：本系统属医学科研场景，不涉及金融行情，颜色语义按通用规范（非 A 股红涨绿跌）。

## 6.3 字体与排版

| 项 | 建议 |
|----|------|
| 字体 | 系统字体栈优先，中文用 PingFang SC / Microsoft YaHei |
| 标题层级 | 板块标题 20px+ 加粗；卡片标题 16px；正文 14px |
| 行高 | 正文 1.6，紧凑标题 1.3 |
| 间距 | 8px 基础栅格，板块间 24-32px 留白 |

## 6.4 组件规范

| 组件 | 规范 |
|------|------|
| 按钮 | 主按钮实心蓝、次按钮描边/浅色；圆角 8px；含 hover/active/disabled 态 |
| 输入框 | 圆角 8px，聚焦态描边主色；检索框 2 行高度 |
| 关键词标签 | 蓝色渐变背景 + 白色文字 + `×` 删除，圆角 pill 形 |
| 复选框 | 自定义样式，选中态主色 |
| 文献卡片 | 浅底卡片 + 细边框 + 12px 圆角，阴影克制 |
| 加载态 | 骨架屏或 spinner，避免生硬转圈 |

## 6.5 去 AI 化设计要点

1. **克制的圆角**：避免全场超大圆角（>16px）与过度胶囊化。
2. **真实的色彩**：以品牌蓝为唯一主色，避免紫→蓝的多色霓虹渐变。
3. **克制的阴影**：轻量阴影，避免浮夸发光/玻璃拟态。
4. **无 emoji 装饰**：界面图标统一用线性 SVG 图标，不使用 emoji 点缀。
5. **真实数据呈现**：文献卡片以信息密度取胜，避免空洞的占位文案。
6. **专业术语**：文案使用医学/科研惯用表达，避免营销腔。
7. **一致的排版**：明确的栅格对齐，避免元素随意漂浮。

## 6.6 响应式与移动端

| 项 | 规范 |
|----|------|
| 移动优先 | 375px 起适配，768px 以上桌面居中限宽（如 max-width 960px） |
| 触控目标 | 按钮/复选框触控区域 ≥ 44px |
| 文献列表 | 移动端标题/PMID 采用弹性换行，避免溢出 |
| 卡片 | 单列堆叠，桌面可双列 |

## 6.7 无障碍与提示

- 关键操作提供明确 feedback（toast/内联提示）。
- AI 生成内容区域标注「AI 生成内容仅供参考」。
- 输入框、按钮具备可读 label 与 aria 属性。
