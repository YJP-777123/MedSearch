# 07 · 开发任务与验收

| 里程碑 | 内容 | 交付物 |

| M1 · 后端基础 | Flask 骨架、配置、MaaS/PubMed 服务封装 | 可运行的 API |

## 7.3 验收标准

| 场景 | 验收条件 |
|------|----------|
| 关键词生成 | 输入 10-300 字描述，返回 3 个中文关键词，标签可删除 |
| 关键词管理 | 可添加关键词，最多 5 个，重复/超限有提示 |
| 文献检索 | 点击检索后返回真实 PubMed 文献，显示 totalCount，每页 9 篇 |
| 文献列表 | 标题中文显示，PMID 正确，可勾选多篇，可分页 |
| AI 总结 | 勾选文献后生成含「关键发现/研究趋势/临床意义」的总结卡片 |
| 查看原文 | 点击跳转 `https://pubmed.ncbi.nlm.nih.gov/{PMID}/` |
| 异常处理 | 空描述/无关键词/未勾选/无结果/接口失败均有明确提示 |
| 移动端 | 375px 宽度下布局正常、触控可用 |
| 设计规范 | 符合 06 设计规范，无明显 AI 化痕迹 |

## 7.4 待确认事项（开发前需拍板）

1. **分页交互**：页码分页 vs 「更多文献」累加加载（默认按需求文案用累加加载）。
2. **检索返回策略**：一次性返回全部 vs 按页请求（默认按页请求）。
3. **前端状态管理**：是否引入 pinia（组件较简单时可不用，默认引入以管理跨页勾选）。
4. **MaaS 模型与密钥**：需提供华为云 MaaS 的具体模型名、Endpoint、API Key。
5. **PubMed 结果排序**：默认相关性排序（relevance）还是最新排序（date），默认 relevance。

## 7.5 开发说明

- 开发将在用户审阅本 SDD 并确认后启动。
- 执行时按 M1 → M2 → M3 → M4 顺序推进，每完成一个里程碑向用户汇报。
- 前端界面开发时加载 `frontend-design` SKILL 落地设计规范。
